🔌 App Integration Guide
🚀 Connect Your Mobile / Web App

This admin portal exposes a clean REST API. Connect any frontend (React Native, Flutter, Next.js) using the endpoints below. Auth uses JWT. Roles are embedded in the token payload.

📡 Base URL
https://api.mrtube.in/v1
🔑 Auth Header
Authorization: Bearer {jwt_token}

📋 Full API Reference

📱 React Native / Flutter
1. Store token in SecureStorage
2. Add header to all requests
3. Handle 401 → redirect to login
4. Role in JWT payload as role
5. Show/hide UI by role
6. WebSocket: wss://api.mrtube.in/ws/admin
🌐 Next.js / React Web
1. Use next-auth or jwt-decode
2. Store token in httpOnly cookie
3. Protect routes in middleware by role
4. API client: axios with interceptors
5. State: Zustand or Redux Toolkit
6. Real-time: socket.io-client
